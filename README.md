# Pati Tejaswini — Developer Portfolio

A focused developer portfolio built with Next.js, React and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import this repository into Vercel. Framework preset: **Next.js**. Build command: `npm run build`.

## Notes

Project links point to source repositories. Claims should be updated only when they are verified against the implementation.
